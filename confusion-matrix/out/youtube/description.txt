The confusion matrix explained visually: accuracy, precision, recall and the F1 score, for Machine Learning (ML), Data Science (DS), Finance and Computer Science (CS).
Learn to read any classifier's confusion matrix, why 99% accuracy can be useless, and how to choose between precision and recall.

Two fraud detectors check 10,000 card payments, 100 of them fraud. One says "we catch 90% of fraud", the other says "90% of our alarms are real", and both are over 99% accurate. Yet one lets 55 of the 100 frauds through, and a detector that never raises an alarm is 99% accurate too. A 26-minute explainer for people who don't think of themselves as "math people".

🌍 WHERE YOU'LL USE IT
• Machine Learning / ML (21:09): the first thing printed after training any classifier; for rare classes report precision and recall, not accuracy alone
• Data Science / DS (21:36): explain a model in plain words: of every 100 alarms this many are real, of every 100 cases we catch this many
• Finance (21:46): fraud detection and credit risk; the cut-off is set by the cost of each kind of mistake
• Computer Science / CS (21:53): spam filters, malware scanners and intrusion detection, where too many false alarms get ignored

📐 KEY FORMULAS
• accuracy = (TP + TN) / total: how often the detector is right overall
• precision = TP / (TP + FP): of everything it flagged, how much was real
• recall (sensitivity) = TP / (TP + FN): of everything real, how much it caught
• specificity = TN / (TN + FP): of everything normal, how much it left alone
• F1 = 2TP / (2TP + FP + FN): the harmonic mean of precision and recall
  TP = true positives (caught), TN = true negatives (correctly left alone),
  FP = false positives (false alarms), FN = false negatives (misses)

✅ WORKED EXAMPLE
• Detector A (TP 90, FN 10, FP 30, TN 9,870): accuracy 99.6%, precision 75%, recall 90%, F1 = 9/11 ≈ 82%
• Detector B (TP 45, FN 55, FP 5, TN 9,895): accuracy 99.4%, precision 90%, recall 45%, F1 60%
• Detector C (TP 99, FN 1, FP 301, TN 9,599): recall 99%, precision ≈ 25%, accuracy 96.98%
• Lazy detector (never alarms): accuracy 99%, recall 0
• Medical test (9, 1, 99, 891): recall 90%, accuracy 90%, precision 9/108 = 1 in 12; in a clinic where half are sick: precision 90%
• Spam filter (270, 30, 10, 690): precision ≈ 96%, recall 90%, accuracy 96%
• Loans (150, 50, 100, 1,700): precision 60%, recall 75%, accuracy 92.5%, F1 = 2/3
• Costs (illustration, a miss = $500, a false alarm = $5): A $5,150, B $27,525, C $2,005, lazy $50,000

🧭 THE RECIPE
1. Draw the grid: truth in the rows, the detector's answer in the columns.
2. Fill the four counts and check the rows add up to the real totals.
3. Precision: read down the alarm column.
4. Recall: read across the real row.
5. Price the mistakes, then set the cut-off. Use accuracy only when the groups are roughly balanced.
